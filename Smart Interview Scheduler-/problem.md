# Problem Statement
A company has:
Multiple interviewers
Multiple candidates
Available time slots
Schedule interviews such that:

✅ No interviewer overlaps
✅ No candidate overlaps
 ✅ Maximum interviews are completed
 # example
 Interviewers:
A : 10-11, 2-4
B : 9-12

Candidates:
C1 : 10-11
C2 : 11-12
C3 : 2-3
# output
A -> C1 at 10-11
B -> C2 at 11-12
A -> C3 at 2-3
# Concepts
Interval Scheduling
Greedy Algorithms
Priority Queue
Calendar Systems
