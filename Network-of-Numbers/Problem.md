A company stores employee IDs in an array ids.
Two IDs are considered connected if they share at least one common digit.

# For example:
123 and 345 are connected (common digit = 3)
456 and 789 are not connected
A group is formed by all directly or indirectly connected IDs.
Return the size of the largest group.

# Example 1

# Input:
ids = [123, 345, 567, 890]
 # Output:
3
